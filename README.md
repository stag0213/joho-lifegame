# ライフゲーム Webアプリ (Conway's Game of Life)

## 概要
本プロジェクトは、高校の「情報Ⅰ」（モデル化とシミュレーション）の授業で活用できる、ライフゲームのWebアプリケーション教材です。
HTML, CSS, JavaScriptを1つのファイル（`index.html`）にまとめているため、サーバー構築や特別な開発環境は一切不要です。ブラウザだけで手軽に動作します。

## 特徴
- **直感的な操作**: マス目（セル）をクリックすることで、生・死の状態を自由に切り替えられます。
- **シミュレーション制御**: 「スタート/ストップ」「1ステップ進める」「クリア」「ランダム配置」機能を搭載。
- **プリセット機能**: 有名なパターン（グライダー、ブリンカー、パルサー）をワンクリックで配置できます。※パルサーの周期3の美しい振動も正確に再現しています。
- **ルール解説付き**: 画面下部にライフゲームの基本ルール（誕生、生存、過疎、過密）を常時表示しています。

## 使い方
1. 作成したHTMLコードをコピーし、メモ帳などのテキストエディタに貼り付けます。
2. ファイル名を `index.html` として保存します（文字コードは UTF-8 を推奨）。
3. 保存した `index.html` をダブルクリックし、Google Chrome や Microsoft Edge などのWebブラウザで開きます。
4. 「スタート」ボタンを押すか、盤面をクリックして独自のパターンを作り、シミュレーションをお楽しみください。

## 情報Ⅰの授業での活用ポイント
- **アルゴリズムとプログラム**:
  - 2次元配列（リストのリスト）を用いたデータ構造（グリッド）の理解。
  - `for`文の多重ループによる、全マス目の走査処理の実践。
  - `if`文による条件分岐（周囲のセルの数に応じた次世代の生死の判定）。
- **モデル化とシミュレーション**:
  - 単純なルールから複雑なパターンが生まれる「創発（Emergence）」の観察。
  - 「1ステップ進める」機能を用いた、手計算（トレース）との突き合わせによるプログラムの正確な理解。
  - 生徒自身が「消えないパターン」を探求するアクティブ・ラーニングの題材として。

## 動作環境
- モダンWebブラウザ（Google Chrome, Microsoft Edge, Safari, Firefoxなど）
- ※JavaScriptが有効になっている必要があります。

## 改変・カスタマイズのヒント
授業や個人の学習用途で自由に改変してご活用ください。以下のようなカスタマイズを行うことで、さらにプログラミングの学びが深まります。
- `COLS`, `ROWS`, `CELL_SIZE` の値を変えて、盤面の広さやマスの大きさを変更する。
- 描画処理 (`ctx.fillStyle`) のカラーコードを変更して、好きな色のデザインにする。
- 新しいプリセットパターン（例：「どんぐり」「スペースシップ」など）の座標を調べ、JavaScriptに追記する。
